01 · The Problem

Mathematical animations are powerful.
The tooling is stuck in 2018.

Manim is the gold standard for code-driven scientific explainer videos. Yet authors spend hours wrestling with Cairo dependencies, manual FFmpeg CLI flags, re-rendering entire videos just to nudge a watermark, and hacking multi-format crops.

You shouldn’t need an entire media ops pipeline just to ship educational animations.

scenes/harmonic_flow.py 
# Plain Python Manim — zero lock-in
from manim import *
from pnp.sdk import ctx

class HarmonicFlow(Scene):
    def construct(self):
        title = Text(
            ctx.params.get("title", "Wave Mechanics"),
            color=ctx.theme.primary,
        )
        wave = ParametricFunction(
            lambda t: np.array([t, np.sin(2*t), 0]),
            t_range=[-4, 4]
        )
        self.play(Write(title), run_time=1.2)
        self.play(
            title.animate.to_edge(UP),
            Create(wave)
        )

03 · The Brand Matrix

One render pass.
Every format. Every brand.

Define brand kits with logos, colors, and typography. Export a matrix of compositions × formats (16:9, 9:16, 1:1) × brand kits. Logos are composited by FFmpeg after render — modifying a placement triggers zero Manim re-renders.

  • 9-point anchor grid with format-specific overrides
  • Color themes injected dynamically via pnp.ctx.theme
  • Full variant gallery with instant previews & batch downloads
  • Configurable render cap prevents accidental explosions
